# BUS course tools

Static teaching tools for BUS-2150 and BUS-3150. The BUS-2150 tools are designed
for in-class exploration followed by a short individual response in Canvas.

## BUS-2150 source routes

- `modules/study-design-bias/`
- `modules/sampling-distribution/`
- `modules/inference-decision/`
- `modules/comparing-groups/`
- `modules/comparing-groups/?lab=anova`
- `modules/categorical-risk/`
- `modules/categorical-risk/?lab=gof`
- `modules/statistical-investigation/`

Normal Area Explorer and Linear Regression Studio remain canonical in their own
source repositories and are linked from this repository's directory page.

## Student-data and accessibility boundary

- No account, analytics, cookies, storage, external fonts, or network calls.
- Every input has a visible or programmatic label.
- Results are expressed in text, not only by color or graphics.
- Each app includes a reproducible starting state and immediate feedback.
- Print styles and an instructor-provided static worksheet support noninteractive use.
- The tools do not submit answers; students record requested responses in Canvas.

The public deployment shell in `rhartlage.github.io` must pin a committed source
revision before any new route is published.
